Your action items

Only you can do these; they unblock phase 1.

  1. Buy code signing: Azure Trusted Signing (cheapest) or an OV/EV certificate, then add the secrets (docs/RELEASING.md). Removes the SmartScreen warning.
  2. Create the update key once: npx tauri signer generate; keep the private key safe; add the secrets and VPET_UPDATE_PUBKEY.
  3. Push to GitHub (a branch is fine) so CI runs for the first time.
  4. Before announcing a release, install it once on a PC or VM without a GPU driver.
